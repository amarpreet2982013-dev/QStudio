# Folder structure

- `app/` Electron main and preload process.
- `renderer/` React application, feature modules, state, and styles.
- `backend/` compiler, backend, cloud, and AI contracts.
- `simulator/` simulator abstraction and mock simulator.
- `ai/` reserved provider adapters and prompt policies.
- `extensions/` extension host API.
- `assets/` packaged visual assets.
- `docs/` product and development documentation.
- `tests/` unit and end-to-end tests.
